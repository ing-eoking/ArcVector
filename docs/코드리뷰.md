이 문서는 **코드를 옆에 두고 읽는 용도**다. 각 절이 실제 소스 조각 하나와 그 조각이 왜 그렇게
생겼는지, 그리고 **리뷰어가 무엇을 확인해야 하는지**를 짝지어 놓았다.

- 코드 블록은 전부 소스에서 줄 범위째로 뽑았다. 손으로 옮긴 것은 없다.

  밀린다. 내용이 어긋나 보이면 링크가 아니라 함수 이름으로 찾으면 된다.
- `☐`로 시작하는 줄이 확인 항목이다. 근거가 코드 안에 있는 것만 적었다.

## 0. 먼저 알아야 할 다섯 가지

이 모듈의 거의 모든 코드가 아래 다섯 중 하나 때문에 그 모양이다. 리뷰 중 "왜 이렇게 복잡하지"
싶은 곳이 나오면 대개 여기로 돌아온다.

### I1. 인덱스 하나 = arcus Map 아이템 하나. 그래프는 캐시다

벡터 하나가 Map 원소 하나이고, usearch 그래프는 **언제든 Map에서 다시 만들 수 있어야 하는
사본**이다. 복제도 영속화도 Map만 따라간다. 그래서 모든 쓰기가 "엔진 먼저, 그래프 나중"이고,
그 반대는 없다.

### I2. usearch 키 = 그 원소의 주소. refcount가 그것을 지킨다

`key → id`가 조회가 아니라 **역참조**다. 원소가 자기 필드 바이트를 들고 있고 그게 id다.
주소가 계속 그 원소를 가리키려면 원소가 해제되면 안 되고, 그래서 그래프가 원소마다 refcount를
하나씩 든다.

### I3. 원소는 링크된 뒤로 불변이다

`FILTER` 술어가 **엔진 락 없이** 원소 바이트를 읽는다(I2 때문에 가능한 일이다). 그러니 링크된
원소를 제자리에서 고치면 읽는 도중에 바뀐다. 값이 바뀌는 것은 언제나 "새 원소를 링크하고 헌
것을 unlink"다. `vsetattr`이 `map_elem_update`를 안 쓰는 이유다.

### I4. 실패할 수 있는 일은 전부 `CLOG_MAP_ELEM_INSERT` 앞에

`do_map_elem_link`가 그 로그를 내보내는 순간 쓰기가 이 노드를 떠난다(복제본·영속화 로그).
그 뒤에 실패하면 **복제본이 master가 포기한 쓰기를 갖는다.** `map_elem_alloc`은 로그를 남기지
않으므로, 할당·정원 확보·그래프 삽입이 전부 그 앞이다.

### I5. 데몬은 죽지 않는다

메모리가 없으면 응답으로 답하지, abort하지 않는다. Rust 표준 컬렉션은 늘리지 못하면 abort하므로
자라는 자료구조는 전부 `try_reserve`를 먼저 부르고, 실패는 에러로 돌아간다.

☐ 새로 추가된 `Vec`/`HashSet`/`HashMap` 삽입이 `try_reserve` 없이 자라지 않는가
☐ `unwrap()`/`expect()`/인덱싱/`panic!`이 명령 경로에 새로 들어오지 않았는가
☐ 락 순서가 `inner`(그래프) → `held`(보유 집합)인가. 반대로 잡는 곳이 하나라도 있으면 교착이다
☐ 레지스트리 가드를 든 채 `Arc<VectorIndex>`를 떨구는 곳이 없는가 (§1.6)

## 1.1 element — 저장 바이트

**`src/handler/arcus/element.rs`** · 순수 함수만. 엔진도 그래프도 여기 안 들어온다.

원소 하나의 배치는 `alen(2) + ATTR(128) + 벡터 + 종단(2)`이다.

**[arcus/element.rs:54-64](../src/handler/arcus/element.rs#L54-L64)**

```rust
impl Layout {
    /// Where the vector begins. Constant, because ATTR has a fixed size.
    pub const VECTOR_OFFSET: usize = HEADER_LEN + ATTR_BYTES;

    pub const fn new(dim: usize, quant: Quant) -> Self {
        Self { dim, quant }
    }

    pub const fn vector_bytes(&self) -> usize {
        self.quant.vector_bytes(self.dim)
    }
```

`VECTOR_OFFSET`이 **상수**인 것이 핵심이다. ATTR이 가변이면 벡터 시작점이 `alen`에 따라
움직이고, `attr_of`와 디코딩이 매번 계산을 하게 된다.

### 벡터는 recovery 빌드에만 들어간다

**[arcus/element.rs:69-83](../src/handler/arcus/element.rs#L69-L83)**

```rust
    /// What a stored element holds.
    ///
    /// The vector is in it only where something reads it back: a rebuild from Map. usearch
    /// already holds one copy, and outside a recovery build nothing ever asks the Map for it —
    /// `vsim KEY` takes its query straight from the graph. At 768 dimensions the vector is
    /// 3072 of the element's 3204 bytes, so leaving it out is most of what an element costs.
    #[cfg(recovery)]
    pub const fn element_len(&self) -> usize {
        Self::VECTOR_OFFSET + self.vector_bytes()
    }

    #[cfg(not(recovery))]
    pub const fn element_len(&self) -> usize {
        Self::VECTOR_OFFSET
    }
```

Map의 벡터를 읽는 곳은 재구축 하나뿐이고, 그건 recovery 빌드에만 있다. `vsim KEY`의 질의
벡터는 그래프에서 읽는다(§1.5 `vector_of`). 768차원 f32면 원소가 3204 → 132 바이트가 된다.

☐ `element_len()`을 쓰는 자리와 `full_stored_len()`을 쓰는 자리가 뒤바뀌지 않았는가 —
  차원 한도만 후자를 쓴다(빌드에 따라 받는 차원이 달라지면 안 되므로)
☐ `#[cfg(recovery)]`로 잘린 `vector` 필드를 읽는 코드가 non-recovery 빌드에서 컴파일되지 않는가

### ATTR 영역은 통째로 다시 쓴다

**[arcus/element.rs:186-203](../src/handler/arcus/element.rs#L186-L203)**

```rust
    pub fn set_attr(&self, buf: &mut [u8], attr: &[u8]) -> Result<(), CodecError> {
        if attr.len() > ATTR_BYTES {
            return Err(CodecError::AttrTooLarge {
                limit: ATTR_BYTES,
                got: attr.len(),
            });
        }
        if buf.len() < Self::VECTOR_OFFSET {
            return Err(CodecError::Truncated {
                need: Self::VECTOR_OFFSET,
                got: buf.len(),
            });
        }
        buf[0..HEADER_LEN].copy_from_slice(&(attr.len() as u16).to_le_bytes());
        buf[ATTR_OFFSET..Self::VECTOR_OFFSET].fill(0);
        buf[ATTR_OFFSET..ATTR_OFFSET + attr.len()].copy_from_slice(attr);
        Ok(())
    }
```

`fill(0)`이 빠지면 안 된다. 엔진이 준 원소 몸통은 **슬랩에 있던 쓰레기**이고, 그 바이트도
그대로 저장되고 복제된다. 갱신에서는 예전 ATTR의 꼬리가 같이 나간다.

☐ ATTR을 쓰는 모든 경로가 `write` 또는 `set_attr`를 지나는가 (직접 `copy_from_slice` 금지)
☐ `set_attr`가 `buf.len()`을 바꾸지 않는가 — 바꾸면 I3의 "교체" 전제가 깨진다

### 헤더 파싱은 신뢰하지 않는다

**[arcus/element.rs:224-236](../src/handler/arcus/element.rs#L224-L236)**

```rust
fn parse_header(buf: &[u8]) -> Result<Header, CodecError> {
    if buf.len() < HEADER_LEN {
        return Err(CodecError::Truncated {
            need: HEADER_LEN,
            got: buf.len(),
        });
    }
    let attr_len = u16::from_le_bytes([buf[0], buf[1]]) as usize;
    if attr_len > ATTR_BYTES {
        return Err(CodecError::LayoutMismatch);
    }
    Ok(Header { attr_len })
}
```

`attr_len`은 **저장된 바이트에서 읽은 값**이다. `ATTR_BYTES`를 넘으면 그 원소는 우리가 쓴 것이
아니거나 형식이 다른 것이므로 슬라이싱 전에 거절한다.

☐ `buf[..]` 슬라이싱 앞에 길이 검사가 있는가 (`attr_of`, `decode` 둘 다)

## 1.2 engine::error — 엔진 코드를 어떻게 읽는가

**`src/handler/arcus/engine/error.rs`**

이 파일에서 리뷰할 것은 사실상 한 줄이다.

**[arcus/engine/error.rs:83-86](../src/handler/arcus/engine/error.rs#L83-L86)**

```rust
/// Whether an engine code means the operation completed.
pub(super) fn completed(code: u32) -> bool {
    code == ENGINE_ERROR_CODE_ENGINE_SUCCESS || code == ENGINE_ERROR_CODE_ENGINE_EWOULDBLOCK
}
```

**`EWOULDBLOCK`은 실패가 아니다.** 동기 복제 master에서 연산은 *이미 성공한 뒤* 호출자를 슬레이브
ack 대기자로 등록한다. "아직 답하지 말라"는 뜻이지 "일어나지 않았다"가 아니다. 실패로 읽으면
방금 link된 원소를 해제하게 되고, `map_elem_free`가 `assert(elem->linked == 0)`에서 죽는다 —
**이 모듈이 실제로 서버를 죽인 적 있는 자리다.**

☐ 새 엔진 호출이 `check()`/`completed()`를 지나는가. 코드를 직접 `== ENGINE_SUCCESS`로 비교하면
  `EWOULDBLOCK`이 실패가 된다
☐ `KeyGone`(Map 없음)과 `ElemGone`(원소 없음)을 뒤섞은 곳이 없는가 — 앞은 그래프를 놓는 근거이고
  뒤는 그냥 `NOT_FOUND`다

## 1.3 engine::elem — 엔진 원소 다루기

**`src/handler/arcus/engine/elem.rs`** · 이 모듈에서 `unsafe`가 가장 많은 파일이다.

### PendingElem — 아직 아무도 못 보는 원소

**[arcus/engine/elem.rs:37-61](../src/handler/arcus/engine/elem.rs#L37-L61)**

```rust
#[must_use = "an uninserted element is invisible; insert it or drop it"]
pub struct PendingElem<'a> {
    store: &'a Store,
    /// The Map this element was reserved for; `insert` cannot be pointed at another.
    key: &'a str,
    item: *mut eitem,
    /// The element's value bytes, inside the engine's allocation. Reserving before the value
    /// is known is the point: allocation is the step most likely to fail, and doing it first
    /// means a graph insert is never paid for and thrown away.
    value: *mut u8,
    value_len: usize,
}

impl Drop for PendingElem<'_> {
    fn drop(&mut self) {
        if self.item.is_null() {
            return;
        }
        let Some(elem_free) = self.store.vtable().map_elem_free else {
            return;
        };
        // SAFETY: a non-null `item` here was never inserted, so it is still ours to free.
        unsafe { elem_free(self.store.handle(), self.store.cookie, self.item) };
    }
}
```

`Drop`이 `map_elem_free`를 부르므로 조기 반환·`?`·패닉 어디서도 누수가 없다. I4가 성립하는
이유가 이것이다 — 몸통을 먼저 잡아 두고, 실패할 수 있는 일을 전부 한 다음, 마지막에 `insert`.

**[arcus/engine/elem.rs:111-139](../src/handler/arcus/engine/elem.rs#L111-L139)**

```rust
    fn publish(mut self, attr: *mut item_attr, replace_if_exist: bool) -> Result<Published> {
        let Some(insert) = self.store.vtable().map_elem_insert else {
            return Err(StoreError::Unavailable);
        };
        let mut replaced = false;
        let mut created = false;
        // SAFETY: ownership of `item` passes to the engine only when the code says completed.
        // `attr` is either null or a live local of the caller frame.
        let code = unsafe {
            insert(
                self.store.handle(),
                self.store.cookie,
                self.key.as_ptr().cast::<c_void>(),
                as_int(self.key.len()),
                self.item,
                replace_if_exist,
                attr,
                ptr::from_mut(&mut replaced),
                ptr::from_mut(&mut created),
                0,
            )
        };
        // `check` counts EWOULDBLOCK as completed, which matters here: the element *is*
        // linked in that case, and freeing it would trip `assert(elem->linked == 0)`.
        check(code)?;
        // The engine owns it now; keep `Drop` from freeing it.
        self.item = ptr::null_mut();
        Ok(Published { created, replaced })
    }
```

`self.item = ptr::null_mut()`가 소유권 이전이다. 이 줄이 `check(code)?` **뒤에** 있어야 한다 —
앞에 있으면 실패한 insert의 원소가 새고, 더 뒤로 밀리면 성공한 insert의 원소를 두 번 해제한다.

☐ `check(code)?` 와 `self.item = null` 의 순서가 그대로인가
☐ `insert`의 반환값 `replaced`를 무시하는 호출자가 있는가 — `vsetattr`은 그것으로 부활을 막는다(§2.4)

### 주소를 잡는 두 가지 — hold_addr / take_addr

**[arcus/engine/elem.rs:375-409](../src/handler/arcus/engine/elem.rs#L375-L409)**

```rust
    /// Take a refcount on one element and report where it lives.
    ///
    /// The address is the graph's key for that element. The refcount is what makes it stay one:
    /// the engine frees an element only once no refcount stands, so an unlinked one keeps its
    /// address instead of handing it to whatever the slab allocates next.
    pub fn hold_addr(&self, key: &str, field: &str) -> Result<HeldAddr<'_>> {
        let elems = self.fetch(key, Some(field))?;
        let addr = match elems.as_slice() {
            Some(items) => items[0] as u64,
            None => return Err(StoreError::ElemGone),
        };
        // The refcount moves to the returned guard.
        std::mem::forget(elems);
        Ok(HeldAddr { store: self, addr })
    }

    /// Read one element and delete it in the same call, keeping the refcount.
    ///
    /// The hold outlives the unlink, which is what lets the caller still use the address to
    /// find the node — and stops the engine handing that address to another element before it
    /// has.
    pub fn take_addr(&self, key: &str, field: &str) -> Result<Option<HeldAddr<'_>>> {
        match self.fetch_with(key, Some(field), true) {
            Ok(elems) => {
                let addr = match elems.as_slice() {
                    Some(items) => items[0] as u64,
                    None => return Ok(None),
                };
                std::mem::forget(elems);
                Ok(Some(HeldAddr { store: self, addr }))
            }
            Err(StoreError::ElemGone) => Ok(None),
            Err(e) => Err(e),
        }
    }
```

`std::mem::forget(elems)`가 요점이다. `Elems`의 `Drop`은 refcount를 반납하는데, 여기서는
**반납하지 않고 `HeldAddr`로 옮긴다.** 그래서 주소가 계속 그 원소를 가리킨다(I2).

`take_addr`는 읽기와 삭제를 한 호출로 한다(`map_elem_get`의 `delete` 플래그). 두 호출로 나누면
그 사이에 쓰기가 들어온다.

☐ `forget` 뒤에 `HeldAddr`(또는 그것을 `keep()`한 결과)가 반드시 그래프나 `release_held`로
  이어지는가 — 끊기면 refcount 누수다
☐ `HeldAddr::keep()`을 부른 자리마다, 그 주소를 받은 쪽이 해제 책임을 진다는 것이 코드로 보이는가

### with_attr_at — 검색 술어의 읽기

**[arcus/engine/elem.rs:411-444](../src/handler/arcus/engine/elem.rs#L411-L444)**

```rust
    /// Read the ATTR of the element at `addr` without looking it up.
    ///
    /// The search predicate's read. A node's key *is* its element's address, so the field it
    /// would otherwise be found by is already answered — this skips the hash lookup and the
    /// refcount pair that `map_elem_get` costs, on a path that runs once per visited node.
    ///
    /// Two things have to hold, because this read takes no engine lock.
    ///
    /// **The element must not be freed.** The graph's held set guarantees that: the predicate
    /// runs with its read lock held and only for keys the set contains.
    ///
    /// **The element must not change.** A linked element is immutable here — every write that
    /// changes a value replaces the element instead of editing it, which is why `vsetattr` does
    /// not use `map_elem_update`. The engine's in-place branch would rewrite these bytes under
    /// this read, and a client's `mop update` still can; see `미해결.md §2`.
    ///
    /// `None` means the engine described the element in a way that cannot be read, or the ATTR
    /// does not decode — either way the caller has no attributes to judge.
    pub fn with_attr_at<T>(
        &self,
        addr: u64,
        layout: Layout,
        f: impl FnOnce(&[u8]) -> T,
    ) -> Option<T> {
        let elems = Elems {
            store: self,
            array: ptr::null_mut(),
            count: 0,
        };
        let value = elems.view(addr as *mut eitem).ok()?.1;
        // The view borrows nothing this owns; there is no hold to release.
        std::mem::forget(elems);
        Some(f(layout.attr_of(value).ok()?))
    }
```

방문 노드마다 도는 경로라 조회도 refcount 쌍도 없이 **주소를 그냥 역참조**한다. 성립 조건이
두 개이고, 둘 다 이 함수 밖에 있다:

1. **해제되지 않을 것** — 그래프의 보유 집합이 읽기 락을 잡은 채, 집합에 있는 키로만 부른다
2. **바뀌지 않을 것** — I3

☐ `with_attr_at`의 호출자가 보유 집합 읽기 락 안인가 (§1.5 `search`의 술어)
☐ 링크된 원소를 제자리에서 고치는 코드가 새로 들어오지 않았는가 (I3 위반)

### Elems::view — 엔진이 준 설명을 검사한다

**[arcus/engine/elem.rs:569-591](../src/handler/arcus/engine/elem.rs#L569-L591)**

```rust
        let field = info.score.cast::<u8>();
        let value = info.value.cast::<u8>();
        let (nfield, nvalue) = (info.nscore as usize, info.nbytes as usize);

        // `nfield` is a `uint8_t` in the element header and `nbytes` a `uint16_t`, so a larger
        // value did not come from one. A Map element is never chunked — the engine sets
        // `naddnl` to zero for this type — and `value` sits exactly `nfield` bytes past the
        // field, which is the one relation that ties the two pointers to the same allocation.
        let sane = !field.is_null()
            && !value.is_null()
            && info.naddnl == 0
            && nfield <= u8::MAX as usize
            && nvalue <= u16::MAX as usize
            && nvalue <= self.store.max_element_bytes() as usize
            // SAFETY: comparing addresses only; neither pointer is read.
            && std::ptr::eq(unsafe { field.add(nfield) }, value);
        if !sane {
            return Err(StoreError::CorruptElement);
        }

        // SAFETY: both pointers are non-null and the lengths are the element's own, checked
        // above against what the header can hold and against each other.
        unsafe { Ok((slice_or_empty(field, nfield), slice_or_empty(value, nvalue))) }
```

`nfield`는 헤더에서 `uint8_t`, `nbytes`는 `uint16_t`다. 그보다 크면 그 바이트는 Map 원소가
아니고, 그대로 슬라이스를 만들면 **할당 밖을 읽는다.** 마지막 조건 `field + nfield == value`가
두 포인터를 같은 할당에 묶는 유일한 관계다.

이건 use-after-free 탐지기가 아니다. 해제된 슬랩은 여전히 매핑되어 있고 보통 다른 원소가
들어 있다. 여기서 걸리는 것은 **말이 안 되는 설명**뿐이다.

☐ 이 검사 다음에서만 `slice_or_empty`가 불리는가

```rust
    pub fn stage(&self, vector: &[u8], owner: u64) -> Result<Staged<'_>> {
        self.check_vector(vector)?;
        // Capacity is settled first, because growing takes `inner`'s write lock. Room for
        // every possible concurrent stage, not just this one: each caller reads `live`
        // before adding to it, so `+ 1` lets N writers reserve for one node between them.
        // `THREAD_SLOTS` is the ceiling on how many can be inside usearch at once.
        self.ensure_capacity(self.live() + THREAD_SLOTS)?;

        let index = self.inner.read().unwrap_or_else(PoisonError::into_inner);
        // A placeholder, not the element's address. The address is known already — the caller
        // allocated the element — but a node keyed by it would be *nameable*: the field bytes
        // are in that allocation, so a search could dereference them and answer with an id
        // whose element is not linked yet, for a write that can still fail. The tag keeps the
        // node invisible until `insert_published` renames it, which is after the link.
        let key = held::STAGED_TAG | self.next_placeholder.fetch_add(1, Ordering::Relaxed);

        // Counted in before the node exists, so the count is never behind the graph.
        let staged = Staged::new(key, owner, &self.in_flight);

        // A failure needs no undo: the key named nothing, so nothing named the node, and
        // `staged` drops on the way out and takes its count with it.
        self.typed_add(&index, key, vector)?;
        Ok(staged)
    }
```

```rust
    pub fn insert_published<E>(
        &self,
        staged: Staged<'_>,
        owner: u64,
        displaced: impl FnOnce() -> Option<u64>,
        link: impl FnOnce() -> std::result::Result<u64, E>,
    ) -> std::result::Result<(), PublishError<E>> {
        // `inner` first and `held` second, everywhere. `clear` takes `inner`'s write lock and
        // then this one, so a call that took them the other way round — and this one needs both,
        // because naming a published node is a `rename` on the graph — would deadlock against it.
        let index = self.inner.read().unwrap_or_else(PoisonError::into_inner);
        let mut held = self.held.write().unwrap_or_else(PoisonError::into_inner);
        let live = staged.owner == owner;

        // The room comes before the element write it gates. A std collection that cannot grow
        // aborts instead of returning, so the growth has to be asked for where the answer can
        // still be a reply. Nothing is written yet, so the only thing to unwind is this call's
        // own node.
        if live && let Err(e) = held.reserve() {
            drop(held);
            drop(index);
            let key = staged.key;
            drop(staged);
            self.drop_node(key);
            return Err(PublishError::Mapping(Error::Index(format!(
                "the held set could not grow: {e}"
            ))));
        }

        let displaced = displaced();
        let written = link();
        let key = staged.key;
        drop(staged);
```

```rust
    pub fn remove_published<E>(
        &self,
        take: impl FnOnce() -> std::result::Result<Option<u64>, E>,
    ) -> std::result::Result<Option<bool>, PublishError<E>> {
        let _slack = InFlight::new(&self.in_flight);
        let mut held = self.held.write().unwrap_or_else(PoisonError::into_inner);

        // While rebuilding, a deleted element is remembered so the refill cannot replay it —
        // and the room for that has to be taken *before* the element goes. Once the engine has
        // deleted it there is no failure left to report: the delete is already on its way to
        // the replicas, and refusing here would answer for a state that no longer exists.
        let tombstone = self.rebuilding.load(Ordering::Acquire);
        if tombstone && let Err(e) = held.reserve_tombstone() {
            return Err(PublishError::Mapping(Error::Index(format!(
                "the held set could not grow: {e}"
            ))));
        }

        let Some(addr) = take().map_err(PublishError::Store)? else {
            return Ok(None);
        };

        // `take` left the caller holding a refcount of its own on the unlinked element, so the
        // address stays valid whether or not the graph had it.
        let had_node = if tombstone {
            held.take_tombstoned(addr)
        } else {
            held.take(addr)
        };
        if had_node {
            self.elements.release(&[addr]);
        }
        drop(held);

        // After the hold, and unchecked: it leaves a node nothing holds, which every lookup
        // already drops.
        if had_node {
            self.drop_node(addr);
        }
        Ok(Some(had_node))
    }
```

tombstone 자리를 **엔진 삭제보다 먼저** 잡는다. 삭제된 뒤에는 실패를 보고할 자리가 없다 —
삭제는 이미 복제본으로 가는 중이다.

☐ `reserve_tombstone`이 `take()` 앞인가

### Drop — 마지막 Arc가 전부 놓는다

**[usearch/index.rs:109-125](../src/handler/usearch/index.rs#L109-L125)**

```rust
impl Drop for AnnIndex {
    fn drop(&mut self) {
        // Every element this graph pinned goes back. Nothing else will do it: the entry that
        // owned this index is already out of the registry by the time the last `Arc` falls, so
        // there is no caller left to ask. Skipped without it, an expired index would keep its

            .held
            .get_mut()

        }
    }
}
```

## 1.6 registry — 이름 → 인덱스

**`src/handler/registry.rs`**

### 발행 시계

**[registry.rs:13-25](../src/handler/registry.rs#L13-L25)**

```rust
/// Ticks once per publish, and orders publishes against the reads that judge them.
///
/// A release is always decided on something read earlier — a metadata read, an engine call's
/// `KeyGone` — and by the time it reaches the registry the name can hold an index registered
/// since, for a Map that exists. [`now`] taken before the read says what "already there" means
/// for that verdict, and [`remove_if_stale`] refuses anything newer.
static CLOCK: AtomicU64 = AtomicU64::new(1);

/// The reading a verdict carries. One atomic load — not a lookup, and it takes no lock, which
/// is what lets the metadata read stay first.
pub fn now() -> u64 {
    CLOCK.load(Ordering::Acquire)
}
```

해제는 **항상 먼저 읽은 것**에 근거해 결정된다(메타데이터 읽기, 엔진의 `KeyGone`). 그 판정이
레지스트리에 도달할 때쯤이면 그 이름이 **다른 인덱스**를 들고 있을 수 있다.

**[registry.rs:205-224](../src/handler/registry.rs#L205-L224)**

```rust
/// Release `name` if what it holds was already answerable when `stamp` was taken.
///
/// Two entries are spared. One published after `stamp` belongs to a Map the verdict never
/// looked at. One not published at all is a `vcreate` mid-flight, and its Map is on its way.
pub fn remove_if_stale(name: &str, stamp: u64) -> bool {
    let mut reg = write();
    match reg.get(name) {
        Some(current) => {
            let at = current.published_at();
            if at == 0 || at >= stamp {
                return false;
            }
            let evicted = reg.remove(name);
            drop(reg);
            sweep::retire(evicted);
            true
        }
        None => false,
    }
}
```

두 항목이 면제된다. `stamp` 이후에 발행된 것(그 판정이 본 적 없는 Map)과, 아직 발행되지 않은 것
(`vcreate` 진행 중, Map이 오는 중).

☐ 그래프를 놓는 새 경로가 `remove_if_stale`/`remove_observed`를 쓰는가 —
  이름만 보고 `remove`하면 방금 등록된 멀쩡한 인덱스를 날린다
☐ `stamp`를 **읽기 앞**에서 집는가. 뒤에서 집으면 면제가 안 된다

### 해체는 가드 밖에서

**[registry.rs:241-247](../src/handler/registry.rs#L241-L247)**

### coldest — 청소의 작업 목록

```rust
pub(in crate::handler) fn coldest(limit: usize) -> Vec<String> {
    let reg = read();
    coldest_of(
        reg.iter()
            .filter(|(_, index)| index.published_at() != 0)
            .map(|(name, index)| (index.accessed_at(), name.as_str())),
        limit,
    )
}

/// [`coldest`] over any entries. Empty if the scratch list cannot be allocated.
fn coldest_of<'a>(entries: impl Iterator<Item = (u64, &'a str)>, limit: usize) -> Vec<String> {
    let mut all: Vec<(u64, &str)> = Vec::new();
    for entry in entries {
        if all.try_reserve(1).is_err() {
            return Vec::new();
        }
        all.push(entry);
    }
    all.sort_unstable();
    all.truncate(limit);
    all.into_iter().map(|(_, name)| name.to_string()).collect()
}
```

전체 엔트리를 읽는다. 그래서 **커넥션이 아니라 스레드가 부른다**(§1.7).

☐ `coldest_of`의 스크래치 `Vec`이 `try_reserve`로 자라는가 (I5)
☐ 미발행 항목이 빠지는가 — 찔러 봐야 `remove_if_stale`이 면제한다

```rust
    // a lookup — it says what "already registered" means for any release this read leads to.

    // its absence means the graph went without the Map going with it.

        // not take the name while its metadata element stands, so it is a dead name until

        // to are closed — so it means a bug, and leaving a name unusable is the worse half of
        // that. Delete it, loudly, and let the name be used again.
        eprintln!(

             rebuild; deleting the Map so the name can be used again"
```

```rust
/// Probe one offered name, if any is offered.
///
/// Called with a command's answer decided but not yet sent, so it does one `getattr` and
/// nothing else — no registry scan, no removal, no teardown. A name that comes back gone goes
/// to the thread; one that answers anything else is dropped, since only `KeyGone` proves
/// something and a transient engine failure must not cost a working index its graph.
pub fn maybe(store: &Store) {
    if OFFERED.load(Ordering::Relaxed) == 0 {
        return;
    }
    let Some(probe) = take_offer() else { return };
    if matches!(store.probe_map(&probe.name), Err(StoreError::KeyGone)) {
        hand_back(probe);
    }
}

/// Take one offered name, or `None` if another connection took the last of them.
///
/// The pop is what makes a name one connection's to probe: the lock is held across taking it and
/// updating [`OFFERED`], so two connections cannot come away with the same one. It is a short
/// lock and a rare one — a round is ten names a second, and every other command turns back at
/// the atomic above.
fn take_offer() -> Option<Probe> {
    let mut state = state();
    let probe = state.offered.pop();
    OFFERED.store(state.offered.len(), Ordering::Relaxed);
    probe
}
```

커넥션이 하는 일 전부다. `OFFERED`는 락의 대체물이 아니라 **락을 안 잡기 위한 앞문**이라
`Relaxed`로 충분하다. 배타성은 `pop`과 `OFFERED` 갱신을 같은 락 안에 둔 것이 만든다.

```rust
/// Hand an entry that has left the registry to the sweeper. **Call with no registry guard held.**
///
/// The last `Arc` runs `AnnIndex::drop`, which hands back a refcount per vector —
/// `map_elem_release` takes the engine's cache lock every hundred — and then destroys the HNSW
/// index. On a large graph that is a long time to spend in front of an answer, and longer still
/// to spend holding the registry's write lock that every name lookup needs.
///
/// If it is not the last `Arc` this only moves a reference, and whichever command still holds
/// one pays when it finishes — that thread was using the index anyway. What this covers is the
/// case the sweep makes: nobody is using it, so nobody but the sweep would pay.
pub(in crate::handler) fn retire(evicted: Option<Arc<VectorIndex>>) {
    let Some(index) = evicted else { return };
    let mut state = state();
    if state.retired.try_reserve(1).is_err() {
        // Nowhere to put it. Tearing it down here costs this thread the time, which still beats
        // leaking the graph.
        drop(state);
        drop(index);
        return;
    }
    state.retired.push(index);
    SWEEPER.wake.notify_one();
}
```

```rust
fn refill(store: &Store, index: &VectorIndex, held: &mut HeldMap) -> Result<usize> {
    let mut kept: Vec<u64> = Vec::new();
    index.ann.reserve(held.len())?;

    let layout = index.ann.layout;
    let mut added = 0usize;
    for (addr, field, value) in held.read(store) {
        if field == META_FIELD.as_bytes() {
            continue;
        }
        let element = layout.decode(&value).map_err(|e| {
            Error::bad_request(format!(
                "{e} in element {}",
                String::from_utf8_lossy(&field)
            ))
        })?;
        let vector = element.vector.to_vec();
        let replayed = index
            .ann
            .add_unless_known(addr, || Ok(Some(vector.clone())))?;
        if replayed {
            // The graph now keys a node by this address, so its refcount has to outlive the
            // snapshot. `keep` is what stops the release below from freeing it.
            added += 1;
            kept.push(addr);
        }
    }
    for addr in kept {
        held.keep(addr);
    }
    Ok(added)
}
```

`add_unless_known`이 보유 집합 쓰기 락 아래에서 판정한다 — `vadd`가 두 등록에 걸쳐, `vdel`이
tombstone에 걸쳐 잡는 바로 그 락이다. 그래서 라이브 경로가 건드린 id는 여기서 이미 알려져 있고
건너뛴다.

☐ 재구축 스레드가 쓰기를 하지 않는가 — 토큰 기록(`stamp`)이 전부 워커에 있는가
☐ `keep`이 그래프에 넘어간 주소에만 불리는가 (§1.3 `HeldMap::drop`)

## 2.1 vcreate

```
① AnnIndex::new    그래프 객체          usearch
② registry::put    이름 claim · 미발행
③ alloc_elem       메타 원소            arcus
④ insert_creating  Map + 원소 + 판정    arcus  ← 되돌릴 수 없는 지점
⑤ publish / unput  마지막, 실패 불가
```

**`resolve`를 지나지 않는 유일한 명령**이다. 아직 인덱스가 아닌 이름을 다루니 당연하다.

**[cmd/index.rs:49-64](../src/handler/cmd/index.rs#L49-L64)**

```rust
    // Registered first, written to the engine last. The engine write is what carries this
    // create off the node — `map_elem_insert` emits `CLOG_MAP_ELEM_INSERT` — so everything that
    // can fail goes in front of it, the registry's own growth included. Answering for a Map
    // already made and then failing would leave only a delete to take it back.
    //
    // The entry lands unpublished, which is what makes the gap safe without holding a lock
    // across the engine call. A command that reads the metadata in here finds no Map and is
    // right about what it saw — so the entry says "not yet" itself, and nothing releases it.
    let (registered, previous) = match registry::put(index) {
        Ok(pair) => pair,
        Err(e) => {
            return Err(Error::Index(format!(
                "the index registry could not grow: {e}"
            )));
        }
    };
```

등록이 엔진을 만지기 **전**이다(I4). 자라야 하는 자료구조가 레지스트리 하나뿐이라 그것을 먼저
치운다. ②와 ④ 사이에는 "이름은 인덱스인데 Map은 없는" 구간이 생기는데, 그때 들어온 명령이
"Map이 없다"고 읽는 것은 **참**이라 시각 대조로도 막히지 않는다. 막는 것은 **미발행 표식**이다.

**[cmd/index.rs:66-81](../src/handler/cmd/index.rs#L66-L81)**

```rust
    // One engine call settles the name. Nothing probes it first: a probe answers about a
    // moment that has already passed, and every case it could report comes back from this
    // call anyway — decided under the engine's own cache lock, so there is no window between
    // the look and the act.
    //
    //   Ok(true)         the name was free; the engine made the Map and took the element
    //   Ok(false)        a Map was there without metadata — not an index, and not ours
    //   Err(ElemExists)  a Map was there with metadata — already an index
    //   Err(BadType)     the name holds something that is not a Map
    //
    // A Map without this element is not an index: `resolve` cannot read it and only `vdrop`
    // can clear it. The engine unlinks the Map again if the element cannot go in, all under
    // that same lock, so that state has no window to exist in either.
    let settled = store
        .alloc_elem(name, element::META_FIELD, &meta.encode(layout))
        .and_then(|pending| pending.insert_creating(engine::index_attr(Some(held), spec.exptime)));
```

**probe하지 않는다.** probe는 이미 지나간 순간에 대한 답이고, 그것이 보고할 수 있는 모든 경우가
insert 결과로 되돌아온다 — 그것도 엔진 캐시 락 안에서 정해진 것이라 보는 것과 하는 것 사이에
창이 없다.

**[cmd/index.rs:83-119](../src/handler/cmd/index.rs#L83-L119)**

```rust
    match settled {
        // Ours, both of them. Publishing is the last step and the only one that cannot fail:
        // from here the entry answers, and a release may take it. Whatever the name held before
        // is a graph whose Map had expired or been evicted, and dropping it here frees the
        // usearch graph and the element refcounts it holds.
        Ok(true) => {
            registered.publish();
            if previous.is_some() {
                eprintln!(
                    "ArcVector: index '{name}' had no Map; released the graph it was built from"
                );
                // Not on this connection's clock: the graph may hold millions of refcounts.
                sweep::retire(previous);
            }
            Ok(Reply::Created)
        }
        // Not ours. Put the registry back — only if the name still holds this call's entry,
        // since a racing `vcreate` displacing it owns what it put — and take the element back
        // out of a Map we did not make: a plain `mop` Map, or one a replication transfer is
        // still filling. The Map is as we found it, since `delete_elem` passes `drop_if_empty`
        // false and emptying it does not drop it.
        Ok(false) => {
            registry::unput(&registered, previous);
            let _ = store.delete_elem(name, element::META_FIELD);
            already_there(store, name)
        }
        Err(e) => {
            registry::unput(&registered, previous);
            match e {
                StoreError::ElemExists => already_there(store, name),
                StoreError::BadType => Err(Error::bad_request(format!(
                    "'{name}' holds an item that is not a Map"
                ))),
                e => Err(e.into()),
            }
        }
    }
```

| insert 결과 | 이름의 상태 | 하는 일 |
|---|---|---|
| `Ok(true)` | 비어 있었다 | 발행, 밀려난 낡은 항목을 `retire` → `CREATED` |
| `Ok(false)` | 메타데이터 없는 Map | 우리 것 아님. `unput` + 원소 되빼기 |
| `Err(ElemExists)` | 이미 인덱스 | recovery면 인수, 아니면 `vdrop` 안내 |
| `Err(BadType)` | Map이 아닌 아이템 | `CLIENT_ERROR` |

`Ok(false)`가 따로 있는 이유는 **메타데이터 없는 Map에는 insert가 성공하기 때문**이다.
`replace_if_exist=false`도 못 막는다 — 덮어쓸 원소가 없으니 그냥 들어간다.

☐ `unput`이 "이름이 아직 이 호출의 항목을 들고 있을 때만" 하는가 (경쟁하는 `vcreate`의 것을
  뺏으면 안 된다)
☐ `Ok(false)`에서 `delete_elem`이 `drop_if_empty=false`인가 — 남의 Map을 비웠다고 지우면 안 된다
☐ 낡은 항목을 놓는 자리가 `Ok(true)` **뒤**인가 (probe 실패로 놓던 예전 코드는 멀쩡한 인덱스를
  날리는 경로였다)

## 2.2 vadd

```
① coords          본문 → f32
② for_write       메타 읽고 소유권      arcus
③ reserve_elem    원소 몸통             arcus

⑤ hold · insert   결과 확정             arcus    ← 되돌릴 수 없는 지점
⑥ hold · rename   주소로 이름 붙이기    usearch
⑦ drop_node       밀어낸 노드           usearch
```

두 저장소에 쓰는 유일한 명령이다. 원칙은 하나 — **양쪽을 먼저 준비하고, 보이게 만드는 것만 한
락 안에서.**

**[cmd/vector.rs:37-54](../src/handler/cmd/vector.rs#L37-L54)**

```rust

    // exactly `maxcount` vectors — the Map is sized `maxcount + 1` for the metadata element

    // whose link failed can leave a node named for an element the Map no longer holds, and
    // a count that runs high would answer OVERFLOWED for an id that fits.

    // pressure, and taking it before the graph insert means a failure costs nothing but this
    // call — no node to unwind.
    let mut pending = match store.reserve_elem(name, id, layout.element_len()) {

        Err(e) => return store_failed(name, stamp, e),
```

정원 사전 검사를 하지 않는 이유가 주석에 있다. 엔진이 정확히 `maxcount`에서 `EOVERFLOW`로
거절하고, **원소를 세는 권위는 엔진**이다. 그래프의 `len`은 아니다 — 링크가 실패한 쓰기가 Map에
없는 원소를 가리키는 노드를 남길 수 있다.

**[cmd/vector.rs:56-64](../src/handler/cmd/vector.rs#L56-L64)**

```rust

    // so no reader can reach it and there is nothing to publish or undo — which is what lets
    // all of this happen outside the lock below. It is also the expensive part: measured at
    // ~370us for a 768-dimension vector against ~0.2us for the mapping write it feeds.
    //
    // Staged under the owner this write started with; the publish compares it against the
    // owner then, so a takeover in between voids the node instead of naming a wiped one.

```

**[cmd/vector.rs:66-94](../src/handler/cmd/vector.rs#L66-L94)**

```rust

    // The node this write displaces comes from the mapping, so the hold contains one engine
    // call and nothing else.
    //
    // That call is the step which leaves this node: `CLOG_MAP_ELEM_INSERT` is emitted from
    // `do_map_elem_link`, so replicas and the persistence log learn of the write there and
    // nowhere earlier — reserving logs nothing. Everything fallible is already done.
    match index.ann.insert_published(
        staged,
        index.owner(),
        // Read inside the hold, so two writes to one id cannot both see the same outgoing
        // element. The refcount comes along and `insert_published` hands it back.
        || store.hold_addr(name, id).ok().map(HeldAddr::keep),
        // The link, then the refcount that keeps the address the graph is about to key by.
        // Reading it back rather than trusting `pending.addr()` is what makes the key the
        // element the Map actually holds, whatever landed in between.
        || {
            // Replacing or landing on a free field are both this command's business, so what
            // `insert` reports about which one happened is not.
            let _replaced = pending.insert()?;
            store.hold_addr(name, id).map(HeldAddr::keep)
        },
    ) {
        Ok(()) => Ok(Reply::Stored),
        Err(PublishError::Store(e)) => store_failed(name, stamp, e),
        // The mapping refused to grow. Nothing was written and nothing is left over, so this
        // is a reply like any other — the daemon does not fall over a write it declined.
        Err(PublishError::Mapping(e)) => Err(e),
    }
```

`displaced` 클로저가 hold **안에서** 도는 것이 §1.5의 확인 항목과 짝이다.

☐ `pending.addr()`를 믿지 않고 `hold_addr`로 **다시 읽는가** — 그 사이에 무엇이 링크됐든 Map이
  실제로 들고 있는 원소가 키가 되어야 한다
☐ `stamp`가 `for_write` **뒤**인가 (이 쓰기의 항목은 이미 발행돼 있다)
☐ `PublishError::Mapping`이 에러 응답이지 abort가 아닌가 (I5)

**[cmd/vector.rs:137-171](../src/handler/cmd/vector.rs#L137-L171)**

```rust
/// `vgetattr <index> <id>` — the stored attributes, read from Map by field.
pub fn vgetattr(store: &Store, name: &str, id: &str) -> Result<Reply> {
    let index = for_read(store, name)?;
    let stamp = registry::now();

    // Only the ATTR is answered, so only the ATTR is copied.
    match store.get_attr(name, id, index.ann.layout) {
        Ok(attr) => {
            let json = String::from_utf8_lossy(&attr);
            Ok(Reply::Body(format!(
                "VALUE {id} {}\r\n{json}\r\nEND\r\n",
                json.len()
            )))
        }
        Err(StoreError::ElemGone) => Ok(Reply::NotFound),
        // The engine described this element in a way that cannot be read. Stop offering the id
        // — a search would keep returning a row nothing can render — and say so. The Map is
        // left alone: deleting on a reading we do not trust is the same bad reading twice.
        Err(StoreError::CorruptElement) => {
            if let Ok(held) = store.hold_addr(name, id) {
                index.ann.forget_unreadable(held.addr());
            }
            eprintln!(
                "ArcVector: element '{id}' of index '{name}' is unreadable; dropped from the graph"
            );
            Err(StoreError::CorruptElement.into())
        }
        // The Map itself is gone, which no read path used to act on.
        Err(StoreError::KeyGone) => {
            map_is_gone(name, stamp);
            Ok(Reply::NotFound)
        }
        Err(e) => Err(e.into()),
    }
}
```

☐ `CorruptElement`에서 Map을 지우지 않는가 — 믿지 못할 읽기로 지우는 것은 같은 나쁜 읽기를 두 번

☐ `KeyGone`에서 `map_is_gone`을 부르는가 (읽기 경로도 그래프를 놓아야 한다)

**[cmd/vector.rs:201-224](../src/handler/cmd/vector.rs#L201-L224)**

## 2.5 vdel

```
① for_write       메타 읽고 소유권
② hold · take     원소 unlink + 주소   arcus  ← 엔진 먼저
③ hold · take     노드 제거            usearch
```

**[cmd/vector.rs:244-283](../src/handler/cmd/vector.rs#L244-L283)**

```rust
/// `vdel <index> <id>`
pub fn vdel(store: &Store, name: &str, id: &str) -> Result<Reply> {
    let index = for_write(store, name)?;
    let stamp = registry::now();

    // Engine first, always: the Map is the copy replicas and the persistence log follow, so a
    // delete that only reached the graph would come back. Under the mapping's hold, so no
    // reader sees one store without the other.
    let mut map_gone = false;
    // The hold outlives the unlink, so the address still means this element while the graph is
    // asked about it. It is released when `taken` drops, after the graph has let go of its own.
    let mut taken = None;
    let removed = index
        .ann
        .remove_published(|| match store.take_addr(name, id) {
            Ok(held) => {
                let addr = held.as_ref().map(HeldAddr::addr);
                taken = held;
                Ok(addr)
            }
            Err(StoreError::KeyGone) => {
                map_gone = true;
                Ok(None)
            }
            Err(e) => Err(e),
        });
    drop(taken);

    // Outside the hold: releasing the registry entry drops the graph, and the mapping lock is
    // inside it.
    if map_gone {
        map_is_gone(name, stamp);
    }
    match removed {
        Ok(Some(_)) => Ok(Reply::Deleted),
        Ok(None) => Ok(Reply::NotFound),
        Err(PublishError::Store(e)) => Err(e.into()),
        // Refused before the element was touched, so the delete simply did not happen.
        Err(PublishError::Mapping(e)) => Err(e),
    }
```

**엔진 먼저**다(I1). 그래프만 지운 삭제는 재구축에서 되살아난다.

`taken`의 hold가 unlink보다 오래 사는 것이 요점이다 — 그동안 주소가 여전히 그 원소를 뜻하므로
그래프에 그 주소를 물어볼 수 있다.

☐ `drop(taken)`이 `remove_published` **뒤**인가
☐ `map_is_gone`이 hold **밖**인가 — 안에서 부르면 레지스트리 해제가 그래프를 떨구는데 그 락이
  hold 안이다

```rust
        // judged — reading twice could straddle a write. That is `k` lookups rather than one
        // per visited node.
        let Ok(elem) = store.hold_elem(&index.name, id) else {
            return false;
        };
        held.borrow_mut().push((key, elem));
        true
    };
```

**FILTER 경로가 이 모듈에서 가장 뜨거운 코드다.** 방문 노드마다 도는데, 키가 곧 주소라
`map_elem_get` 없이 역참조한다(§1.3). 통과한 것만 hold하므로 hold 횟수가 `k` 수준이지 방문 노드
수가 아니다.

```rust
        let attr = if !with_attr {

            Some(attr)
```

## 2.7 vdrop · vlist · vstats

**[cmd/index.rs:161-177](../src/handler/cmd/index.rs#L161-L177)**

```rust
pub fn vdrop(store: &Store, name: &str) -> Result<Reply> {
    // The Map goes first: a real failure has to leave the registry alone, or the index
    // stops serving a Map that is still there and the client hears DROPPED anyway.
    // Attempted regardless of the registry, so vdrop can clear an orphan Map.
    let dropped = match store.drop_map(name) {
        Ok(()) => true,
        Err(StoreError::KeyGone) => false,
        Err(e) => return Err(e.into()),
    };
    let known = registry::remove(name);

    Ok(if known || dropped {
        Reply::Dropped
    } else {
        Reply::NotFound
    })
}
```

Map을 먼저 지운다. 진짜 실패는 레지스트리를 건드리면 안 된다 — 아직 있는 Map을 인덱스가
안 섬기게 되고, 클라이언트는 `DROPPED`를 듣는다. 레지스트리와 무관하게 시도하므로 고아 Map도
치울 수 있다.

☐ `known || dropped`인가 (둘 중 하나만 있어도 뭔가 지운 것이다)

`vlist`는 **어느 저장소도 부르지 않는다** — 레지스트리만 읽는다. `vstats`는 usearch만 부른다.

# 부록 · 리뷰 체크리스트 한 장

**전역**

☐ 자라는 컬렉션이 `try_reserve`를 지나는가 (I5)
☐ 명령 경로에 `unwrap`/`expect`/`panic!`/슬라이스 인덱싱이 새로 없는가
☐ 락 순서 `inner` → `held`
☐ 레지스트리 가드를 든 채 `Arc<VectorIndex>`를 떨구지 않는가

**엔진 경계**

☐ 새 호출이 `check()`를 지나는가 (`EWOULDBLOCK` = 성공)
☐ `abi.rs`의 `REQUIRED`에 그 함수가 있는가, 선언 순서대로인가
☐ 커넥션 없는 스레드가 키를 받는 API를 부르지 않는가

**주소를 키로 쓰는 것에서 오는 것**

☐ `forget(elems)` 뒤의 refcount에 주인이 있는가
☐ `take`가 `true`를 준 뒤 **락을 놓기 전에** 반납하는가
☐ 링크된 원소를 제자리에서 고치지 않는가 (I3)
☐ 역참조가 보유 집합 읽기 락 안인가

**그래프를 놓는 것**

☐ 엔진이 "없다"고 말한 뒤에만 놓는가
☐ `stamp`를 읽기 앞에서 집는가
☐ `remove_if_stale` / `remove_observed`를 쓰는가 (이름만으로 `remove` 금지)

**순서**

☐ 실패할 수 있는 일이 전부 `map_elem_insert` 앞인가 (I4)
☐ 삭제가 엔진 먼저인가 (I1)
