# 통계 지표 분석

## 기본 통계 지표

### stats

일반적인 서버 동작 상태와 명령 수행 현황을 확인할 수 있는 통계 정보입니다.

```
STAT pid 3150
STAT uptime 0
STAT time 1778743208
...
END
```

주요 통계 항목은 아래와 같습니다.

> 그 외 통계 항목은 서버 상태, 명령 수행 현황, 메모리 사용량, 데이터 저장 상태 등의 정보를 포함합니다.

| 항목 | 설명 |
| :--- | :--- |
| `pid` | 서버 프로세스 ID |
| `uptime` | 서버 실행 시간(초) |
| `time` | 현재 Unix Timestamp |
| `version` | 서버 버전 |
| `curr_connections` | 현재 연결된 클라이언트 수 |
| `total_connections` | 서버 실행 이후 누적 연결 수 |
| `cmd_{command}` | `{command}` 명령 수행 횟수 |
| `{command}_hits` | `{command}` 명령 캐시 적중 횟수 |
| `{command}_misses` | `{command}` 명령 캐시 비적중 횟수 |
| `bytes_read` | 네트워크로 수신한 트래픽 크기(Byte) |
| `bytes_written` | 네트워크로 송신한 트래픽 크기(Byte) |
| `curr_items` | 현재 저장된 데이터 개수 |
| `total_items` | 누적 저장 데이터 개수 |
| `evictions` | 메모리 부족으로 제거된 데이터 개수 |
| `reclaimed` | 만료 데이터 공간 재사용 횟수 |
| `outofmemorys` | 메모리 부족으로 저장 실패한 횟수 |
| `engine_maxbytes` | 데이터 저장용 최대 메모리 크기(MB) |
| `engine_malloced` | 엔진에서 할당한 실제 메모리 크기 |

### stats settings

현재 서버에 적용된 설정 정보를 조회합니다.

```
STAT maxbytes 67108864
STAT maxconns 1024
STAT tcpport 11211
...
END
```

주요 통계 항목은 다음과 같습니다.

> 그 외 통계 항목은 네트워크, 크기 및 개수 제한, 확장 모듈 등의 설정 정보를 포함합니다.

| 항목 | 설명 |
| :--- | :--- |
| `maxbytes` | 데이터 저장용 최대 메모리 크기(Byte) |
| `maxconns` | 허용 가능한 최대 동시 접속 수 |
| `tcpport` | TCP 통신 포트 번호 |
| `verbosity` | 로그 출력 레벨 |
| `evictions` | 메모리 부족 시 Eviction 허용 여부 |
| `num_threads` | 요청 처리에 사용할 스레드 개수 |
| `detail_enabled` | Prefix 상세 통계 수집 여부 |

### stats items

엔진 내 데이터 관리 상태 정보를 조회합니다.

> 해당 통계 정보의 항목과 의미는 사용 중인 엔진에 따라 달라질 수 있습니다.

- **Default Engine**
  - 데이터가 저장된 Slab Class에 대해서만 출력
  - 통계 항목은 `items:<classid>:<name>` 형식으로 출력
    - `<classid>` : Slab Class 번호

```
STAT items:0:number 2000002
STAT items:0:age 5401
STAT items:0:evicted 0
...
END
```

주요 통계 항목은 다음과 같습니다.
> 그 외 통계 항목은 내부 데이터 관리 정보를 포함합니다.

| 항목 | 설명 |
| :--- | :--- |
| `number` | 저장된 데이터 개수 |
| `age` | 가장 오래된 데이터의 저장 시간 |
| `evicted` | 축출된 데이터 개수 |
| `evicted_time` | 마지막 축출 이후 경과 시간 |
| `outofmemory` | 메모리 부족으로 저장 실패한 횟수 |
| `reclaimed` | 만료된 데이터 공간 재사용 횟수 |

### stats slabs

> [!TIP] 💡 도움말
>
> slabs 통계 지표의 항목과 의미는 사용 중인 엔진에 따라 달라질 수 있습니다.

엔진의 메모리 관리 정보를 조회합니다.

- **Default Engine**
  - SM 영역에 대한 통계 정보가 가장 먼저 출력
  - 이후 데이터가 저장된 Slab Class에 대해서만 출력
  - SM 영역의 통계 항목은 `SM:<name>` 형식으로 출력
  - Slab Class별 통계 항목은 `<classid>:<name>` 형식으로 출력
    - `<classid>` : Slab Class 번호
  - 각 Slab Class별 통계 정보 출력 이후, 통합 통계 정보가 출력

```
STAT SM:used_num_classes 0
STAT SM:free_num_classes 0
STAT SM:used_min_classid 709
...
STAT 0:chunk_size 262144
STAT 0:total_pages 1
STAT 0:used_chunks 1
...
STAT active_slabs 1
STAT memory_limit 67108864
STAT total_malloced 1048576
END
```

SM 영역에 대한 주요 통합 통계 항목은 다음과 같습니다.
> 그 외 통계 항목은 SM 영역의 Slot 사용 상태 및 공간 관리 정보 등을 포함합니다.

| 항목 | 설명 |
| :--- | :--- |
| `used_total_space` | 사용 중인 Slot 총 크기(Byte) |
| `free_avail_space` | 사용 가능한 Slot 총 크기(Byte) |

Slab 영역에 대한 주요 통계 항목은 다음과 같습니다.
> 그 외 통계 항목은 Chunk 사용 상태, 메모리 요청 정보 등을 포함합니다.

| 항목 | 설명 |
| :--- | :--- |
| `chunk_size` | Chunk 크기(Byte) |
| `total_chunks` | 할당된 Chunk 총 개수 |
| `used_chunks` | 사용 중인 Chunk 개수|
| `free_chunks` | 사용 가능한 Chunk 개수 |

통합 통계 항목은 다음과 같습니다.

| 항목 | 설명 |
| :--- | :--- |
| `active_slabs` | 현재 사용 중인 Slab Class 개수 |
| `memory_limit` | [기본 통계 지표](#기본-통계-지표)의 `engine_maxbytes`와 동일 |
| `total_malloced` | [기본 통계 지표](#기본-통계-지표)의 `engine_malloced`와 동일 |

## Prefix 통계 지표

### stats prefixes

모든 Prefix별 데이터 저장 통계 정보입니다.

```
stats prefixes
PREFIX <null> itm 1 kitm 1 litm 0 sitm 0 mitm 0 bitm 0 tsz 80 ktsz 80 ltsz 0 stsz 0 mtsz 0 btsz 0 time 20260514204830
...
END
```

- Prefix 별로 하나의 `PREFIX` 블록 안에 `항목 값` 형태로 공백(Space)을 구분자로 하여 출력
- Prefix가 지정되지 않은 Key의 경우, `<null>` Prefix로 지정

통계 항목은 다음과 같습니다.

| 항목 | 설명 | 항목 | 설명 |
| :--- | :--- | :--- | :--- |
| `itm` | 전체 데이터 개수 | `kitm` | KV 타입 데이터 개수 |
| `litm` | List 타입 데이터 개수 | `sitm` | Set 타입 데이터 개수 |
| `mitm` | Map 타입 데이터 개수 | `bitm` | B+Tree 타입 데이터 개수 |
| `tsz` | 전체 데이터 사용 크기(Byte) | `ktsz` | KV 타입 데이터 사용 크기(Byte) |
| `ltsz` | List 타입 데이터 사용 크기(Byte) | `stsz` | Set 타입 데이터 사용 크기(Byte) |
| `mtsz` | Map 타입 데이터 사용 크기(Byte) | `btsz` | B+Tree 타입 데이터 사용 크기(Byte) |
| `time` | Prefix 생성 시간 |

### stats detail dump

모든 Prefix별 명령 수행 통계 정보입니다.

```
PREFIX <null> get 0 hit 0 set 1 del 0 inc 0 dec 0 lcs 0 lis 0 lih 0 lds 0 ldh 0 lgs 0 lgh 0 scs 0 sis 0 sih 0 sds 0 sdh 0 sgs 0 sgh 0 ses 0 seh 0 mcs 0 mis 0 mih 0 mus 0 muh 0 mds 0 mdh 0 mgs 0 mgh 0 bcs 0 bis 0 bih 0 bus 0 buh 0 bds 0 bdh 0 bps 0 bph 0 bms 0 bmh 0 bgs 0 bgh 0 bns 0 bnh 0 pfs 0 pfh 0 pgs 0 pgh 0 gps 0 gph 0 gas 0 sas 0
...
END
```

- Prefix 별로 하나의 `PREFIX` 블록 안에 `항목 값` 형태로 공백(Space)을 구분자로 하여 출력
- Prefix가 지정되지 않은 Key의 경우, `<null>` Prefix로 지정

통계 항목은 다음과 같습니다.

**Key-Value 제어 명령 통계 항목**

| 항목 | 설명 | 항목 | 설명 |
| :--- | :--- | :--- | :--- |
| `get` | **get** 명령 수행 횟수 | `hit` | **get** 명령 조회 성공 횟수 |
| `set` | **set** 명령 수행 횟수 | `del` | **delete** 명령 수행 횟수 |
| `inc` | **incr** 명령 수행 횟수 | `dec` | **decr** 명령 수행 횟수 |

**속성 제어 명령 통계 항목**

| 항목 | 설명 | 항목 | 설명 |
| :--- | :--- | :--- | :--- |
| `gas` | **getattr** 명령 수행 횟수 | `sas` | **setattr** 명령 수행 횟수 |

**컬렉션 제어 명령 통계 항목**

컬렉션 제어 명령의 통계 항목명은 `접두어 + 명령 코드 + 접미사` 형태의 세 부분으로 구성됩니다.

접두어는 컬렉션 타입 또는 특정 명령을 나타냅니다.

| 접두어 | 설명 | 접두어 | 설명 |
| :--- | :--- | :--- | :--- |
| `l*` | List 타입 | `s*` | Set 타입 |
| `m*` | Map 타입 | `b*` | B+Tree 타입 |
| `pf*` | B+Tree 타입의 Position 연산 | `pg*` | B+Tree 타입의 Get By Position 연산 |

> `pf`, `pg` 항목은 별도의 명령 코드를 가지지 않습니다.

명령 코드는 특정 명령을 나타냅니다.

| 명령 코드 | 설명 | 명령 코드 | 설명 |
| :--- | :--- | :--- | :--- |
| `*c*` | **create** 연산 | `*i*` | **insert** 연산 |
| `*u*` | **update** 연산 | `*p*` | **incr** 연산 |
| `*m*` | **decr** 연산 | `*g*` | **get** 연산 |
| `*e*` | **exist** 연산 | `*n*` | **count** 연산 |
| `*f*` | **position** 연산 | `*d*` | **delete** 연산 |

접미사는 수행 횟수 또는 성공 횟수를 나타냅니다.

| 접미사 | 설명 | 접미사 | 설명 |
| :--- | :--- | :--- | :--- |
| `*s` | 수행 횟수 | `*h` | 성공 횟수 |

## ZooKeeper 관련 통계 지표

> [!TIP] 💡 도움말
>
> ZooKeeper 관련 통계 지표는 클러스터 기능 사용 시 지원합니다.

### stats zookeeper

현재 서버에 적용된 ZooKeeper 관련 설정 정보를 조회합니다.

```
STAT zk_libversion 3.5.9-p3
STAT zk_timeout 30000
STAT zk_failstop on
...
END
```

주요 통계 항목은 다음과 같습니다.

> 그 외 통계 항목은 클러스터 관련 설정 및 상태 정보를 포함합니다.

| 항목 | 설명 |
| :--- | :--- |
| `zk_libversion` | ZooKeeper 의존성 라이브러리 버전 정보 |
| `zk_timeout` | ZooKeeper 세션 타임아웃 시간(초) |
| `zk_failstop` | ZooKeeper 세션 기반 자동 Fail-stop 여부 |
| `zk_ready` | 서버가 클러스터에서 서비스 가능한 상태인지 여부 |
