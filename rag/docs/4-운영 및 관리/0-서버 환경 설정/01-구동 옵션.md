# 구동 옵션

## 구동 구문

Arcus Memcached는 명령줄 인터페이스(CLI)에서 다음과 같이 구동할 수 있습니다.
설정 파일 지정과 개별 옵션 입력은 선택적으로 사용할 수 있으며, 혼용이 가능합니다.

```regex
memcached [<config_file>] [<options> ...]
```

**매개변수 (Parameters)**

- `<config_file>` (선택)
  - 서버 구동 옵션이 텍스트로 정의된 설정 파일(`.conf`)의 경로
  - 파일 내부는 `설정명=값` 형태로 한 줄에 하나씩 작성 (`#` 기호로 시작하는 줄은 주석으로 처리)

- `<options>` (선택)
  - 서버 구동 옵션을 직접 입력하는 명령줄(CLI) 개별 인자
  - `옵션문자 값` 형태로 작성하며, 여러 옵션을 함께 사용할 경우 공백(Space)으로 구분
  - 설정 파일과 함께 사용될 경우, CLI 옵션이 우선 적용

## 상세 옵션 설정

옵션의 **데이터 타입**에 따라 입력 방식이 다릅니다.
> ※ 일부 옵션은 사용 방식이 다를 수 있으므로, 상세 내용은 각 항목의 설명란 참조
- `String` : 문자열 값 지정
- `Integer` : 정수 값 지정
- `Float` : 실수 값 지정
- `Boolean` : 설정 방식에 따라 상이
  - **CLI 환경** : 값 없이 옵션 문자만 지정 (기본값 반대 상태 적용)
  - **설정 파일** : `true/false` 값 지정


### 필수 옵션

| 설정명 | 옵션문자 | 데이터 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **`engine_path`** | `-E` | String | 없음 | 엔진 라이브러리 파일 경로 |

> [!WARNING] ⚠️ 주의 사항
>
> 필수 옵션은 설정 파일 혹은 CLI 옵션 중 하나를 통해 반드시 제공되어야 합니다.
> 필수 옵션이 누락된 경우, 서버는 정상적으로 구동되지 않습니다.

### 선택 옵션

#### 일반 및 프로세스 설정

| 설정명 | 옵션문자 | 데이터 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **`daemonize`** | `-d` | Boolean | false | 백그라운드(데몬) 프로세스 형태로 구동 |
| **`pid_file`** | `-P` | String | 없음 | 프로세스 ID(PID)를 저장할 파일 경로 지정 <br> (`daemonize` 활성화 시만 사용 가능) |
| **`username`** | `-u` | String | 없음 | 지정한 계정의 권한으로 프로세스 구동 <br> (`root` 계정으로 실행 시 필수) |
| **`use_cas`** | `-C` | Boolean | true | CAS 연산 활성화 여부 <br> (비활성화 시 `cas_unique`는 0으로 고정) |
| **`prefix_delimiter`** | `-D` | Character | `:` | 키의 [`delimiter`](../../2-핵심%20개념/01-데이터%20모델.md#key) 지정 |
| **`maxcore`** | `-r` | Boolean | false | 코어 덤프 파일 크기 제한 해제 여부 <br> **(※ 설정 파일 : 1 = 해제, 0 = 미해제)** |
| **`threads`** | `-t` | Integer | 4 | 요청 처리에 사용할 스레드 개수 지정 <br> (CPU 코어 수에 맞출 것을 권장) |

#### 로깅 및 통계 지표 설정

| 설정명 | 옵션문자 | 데이터 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **`verbosity`** | `-v` `-vv` `-vvv` | Integer | 0 | 로그 출력 레벨 <br> **(※ CLI 환경 : `v`를 연속 표기)** <br> • `0` : Warning (기본값) <br> • `1` : Info (`-v`) <br> • `2` : Debug (`-vv`) <br> • `3` : Detail (`-vvv`) |
| **`allow_detailed`** | `-q` | Boolean | true | `stats detail` 명령어 허용 여부 |
| **`detail_enabled`** | 없음 | Boolean | false | Prefix 상세 통계 수집 여부 <br> (`-D` 옵션 지정 시 자동 활성화) |

#### 네트워크 및 연결 설정

| 설정명 | 옵션문자 | 데이터 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **`port`** | `-p` | Integer | 11211 | TCP 통신 포트 번호 지정 <br> (0 입력 시 비활성화) |
| **`udpport`** | `-U` | Integer | 0 | UDP 통신 포트 번호 지정 <br> (0 입력 시 비활성화) |
| **`listen`** | `-l` | String | 0.0.0.0 | 바인딩할 IP 주소 지정 <br> (0.0.0.0 입력 시 모든 주소에서 접속 허용) |
| **`maxconns`** | `-c` | Integer | 1024 | 허용 가능한 최대 동시 접속 수 |
| **`backlog`** | `-b` | Integer | 1024 | [연결 대기 큐 크기](https://man7.org/linux/man-pages/man2/listen.2.html) |
| **`reqs_per_event`** | `-R` | Integer | 20 | 하나의 연결당 처리할 최대 요청 수 지정 |
| **`protocol`** | `-B` | String | auto | 통신 프로토콜 지정 <br> • `auto` : 프로토콜 자동 감지 <br> • `ascii` : ASCII only <br> • `binary` : Binary only (비권장) |
| **`socketpath`** | `-s` | String | 없음 | UNIX 소켓 통신 파일 경로 지정 |
| **`access`** | `-a` | Integer | 0700 | UNIX 소켓 접근 권한 (8진수) |

#### 메모리 설정

> 메모리 설정은 사용 중인 엔진에 따라 동작 방식이 다를 수 있습니다.

- Default Engine

| 설정명 | 옵션문자 | 데이터 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **`memory_limit`** | `-m` | Integer | 64 | 데이터 저장용 최대 메모리 크기(MB) |
| **`item_size_max`** | `-I` | Integer | 1M | 데이터 최대 크기(Byte) <br> 용량 단위 입력값(K, M) 지원 <br> (최솟값: 1K, 최댓값: 128M) |
| **`eviction`** | `-M` | Boolean | true | 메모리 부족 시 Eviction 허용 여부 |
| **`factor`** | `-f` | Float | 1.25 | Slab Class 별 Chunk 크기 증가 비율 <br> (1보다 큰 값 입력) |
| **`chunk_size`** | `-n` | Integer | 48 | 최소 Chunk 크기(Byte) |
| **`preallocate`** | `-L` | Boolean | false | 대용량 메모리 페이지 사용 여부 설정 |
| **`lock_memory`** | `-k` | Boolean | false | 페이지 메모리 전체 잠금 처리(스왑 방지) |

#### 엔진 설정

| 설정명 | 옵션문자 | 데이터 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- | :--- |
| **`engine_config`** | `-e` | String | 없음 | 엔진 전용 설정 |

> 아래 설정명은 `engine_config` 옵션 및 엔진 설정 파일 전용으로 이외의 설정에서는 사용이 불가합니다.
>
> 형식은 `설정명=값` 형태로 작성하며, `;`를 구분자로 여러 설정을 지정할 수 있습니다.

| 설정명 | 데이터 타입 | 기본값 | 설명 |
| :--- | :--- | :--- | :--- |
| **`max_list_size`** | Integer | 50000 | List 타입에서 저장할 수 있는 최대 요소 개수 |
| **`max_set_size`** | Integer | 50000 | Set 타입에서 저장할 수 있는 최대 요소 개수 |
| **`max_map_size`** | Integer | 50000 | Map 타입에서 저장할 수 있는 최대 요소 개수 |
| **`max_btree_size`** | Integer | 50000 | B+Tree 타입에서 저장할 수 있는 최대 요소 개수 |
| **`max_element_bytes`** | Integer | 16384 | 컬렉션 요소의 최대 크기(Byte) |
| **`scrub_count`** | Integer | 96 | [scrub](../../3-명령어/2-고급%20제어%20명령어/03-데이터%20관리%20명령.md#scrub) 수행 시 제거 단위  |
| **`config_file`** | String | 없음 | 엔진 설정 파일 경로 <br> 설정 파일과 동일한 형식으로 작성 가능 |
