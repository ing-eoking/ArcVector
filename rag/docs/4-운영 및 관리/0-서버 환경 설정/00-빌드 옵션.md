# 빌드 옵션

## 빌드 구문

소스 코드에서 Arcus Memcached를 빌드할 때 `configure` 스크립트를 통해 빌드 방식과 포함할 기능을 제어할 수 있습니다.

```regex
configure [<option> ...]
```

**매개변수 (Parameters)**

- `<option>` (선택)
  - 설치 경로, 기능 활성화 여부, 외부 패키지 경로 등을 지정하는 옵션 목록
  - 공백(Space)을 구분자로 사용하여 나열
  - 사용 가능한 옵션은 상세 옵션을 참고

## 상세 옵션

> [!TIP] 💡 도움말
>
> `$PATH`은 실제 경로로 대체해야 하는 **자리 표시자**입니다.
>
> 예를 들어 `/home/user/arcus`와 같이 실제 경로를 직접 입력합니다.

**설치 경로 설정**

| 옵션 | 기본값 | 설명 |
| :--- | :--- | :--- |
| `--prefix=$PATH` | `/usr/local` | Arcus Memcached 프로그램이 설치될 루트 경로 |

**의존성 라이브러리 경로 설정**

> [!INFO] 🔎 참고 사항
>
> 시스템 기본 경로(`/usr`, `/usr/local`)가 아닌 별도 경로에 설치된 경우, 해당 경로를 직접 지정합니다.

| 옵션 | 설명 |
| :--- | :--- |
| `--with-libevent=$PATH` | libevent 라이브러리 설치 경로 지정 |
| `--with-zookeeper=$PATH` | ZooKeeper 라이브러리 설치 경로 지정 |
| `--with-sasl=$PATH` | SASL 라이브러리 설치 경로 지정 |

**기능 활성화**

| 옵션 | 설명 |
| :--- | :--- |
| `--enable-zk-integration` | ZooKeeper 연동을 통한 캐시 클러스터 기능 활성화 |
| `--with-zk-reconfig` | ZooKeeper 동적 재구성(Dynamic Reconfiguration) 기능 활성화 |
| `--enable-sasl` | SASL 인증 기능 활성화 |
