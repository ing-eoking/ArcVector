# 빌드 및 실행 (Build and Run)

## 소스 코드 빌드 및 설치 가이드

본 문서는 Arcus Memcached와 그 의존성 라이브러리를 동일한 사용자 정의 경로에 통합 설치하여, 시스템 환경과 격리된 안정적인 운영 환경을 구축하는 전체 과정을 안내합니다.

###  

### 1. 사전 필수 패키지 설치

#### 1.1 설치 경로 정의

본 가이드에서는 모든 설치가 이루어질 통합 경로를 `$ARCUS_HOME`으로 정의합니다.

```bash
# 1. 원하는 설치 경로를 지정합니다. (예: /home/arcus)
export ARCUS_HOME=/home/arcus

# 2. 설치 폴더를 생성합니다.
mkdir -p $ARCUS_HOME
```

> [!WARNING] ⚠️ 주의 사항
> 지정한 경로에 쓰기 권한이 없을 경우, 모든 작업은 `sudo`로 실행해야 합니다.

#### 1.2 OS별 필수 패키지 설치

컴파일에 필요한 필수 도구인 **GCC**, **Make**, **Autotools**를 운영체제 환경에 맞게 설치합니다.

- CentOS / RHEL / Rockylinux
```bash
sudo yum install gcc make which libtool
```
- Ubuntu / Debian
```bash
sudo apt-get install build-essential libtool
```
- macOS (Homebrew)
```bash
brew install autoconf automake libtool
```

### 2. 소스 코드 다운로드

공식 배포판(Tarball) 또는 Git 저장소를 통해 소스 코드를 다운로드합니다.

- 공식 배포판 다운로드 (권장)
```bash
wget https://github.com/naver/arcus-memcached/releases/download/1.16.0/arcus-memcached-1.16.0.tar.gz
tar -zxvf arcus-memcached-1.16.0.tar.gz
cd arcus-memcached-1.16.0
```

- Git 저장소를 통한 다운로드
```bash
git clone https://github.com/naver/arcus-memcached.git
cd arcus-memcached
git switch -d 1.16.0
./config/autorun.sh
```

### 3. 의존성 라이브러리 설치

Arcus Memcached 구동에 필요한 의존성 라이브러리(libevent, arcus-zookeeper, cyrus-sasl)를 설치합니다. 
소스 코드 내 포함된 쉘 스크립트를 사용하여 일괄 설치를 진행합니다.

#### 3.1 설치 스크립트 실행

`arcus-memcached` 소스 디렉터리 최상단에서 아래의 명령어를 실행하여 설치 경로를 지정합니다.

```bash
./deps/install.sh $ARCUS_HOME
```
::: tip ⚠️ 주의사항
명령어 뒤에 특정 설치 경로(`$ARCUS_HOME`)를 지정하지 않으면 기본 시스템 경로(`/usr/local`)에 설치됩니다.
:::

### 4. 컴파일 및 설치

의존성 라이브러리 설치가 완료되면, ARCUS 메인 프로그램을 빌드하고 설치합니다. 앞서 정의한 환경 변수 `$ARCUS_HOME`을 사용하여 설치 경로(--prefix)와 각 의존성 라이브러리의 링크 경로를 명시해야 합니다.

```bash
./configure --prefix=$ARCUS_HOME --with-libevent=$ARCUS_HOME
make
make install
```

빌드와 관련된 상세한 가이드는 [빌드 옵션](../4-운영%20및%20관리/0-서버%20환경%20설정/00-빌드%20옵션.md) 문서를 확인하시길 바랍니다.

## 빠른 실행(Quick Start) 가이드

### 1. Arcus Memcached 서버 실행

설치가 완료된 바이너리를 사용하여 Arcus Memcached를 구동합니다.

(포트: 11211, 메모리: 64MB 설정 예시)

```bash
$ARCUS_HOME/bin/memcached \
-E $ARCUS_HOME/lib/default_engine.so \
-p 11211 \
-m 64
```

서버 구동 시 사용하는 옵션에 대한 상세한 가이드는 [구동 옵션](../4-운영%20및%20관리/0-서버%20환경%20설정/01-구동%20옵션.md) 문서를 확인하시길 바랍니다.

### 2. 텔넷(Telnet)을 통한 동작 점검

서버가 정상적으로 구동되었는지 확인하기 위해 텔넷을 사용하여 간단한 데이터 입출력 테스트를 수행합니다.

#### 2.1 서버 접속

```bash
telnet localhost 11211
```

#### 2.2 데이터 저장 테스트 (set)

서버에 `hello`라는 Key로 `arcus`라는 Value를 60초 동안 저장하도록 명령합니다.

- 입력

```
set hello 0 60 5
arcus
```

- 정상 응답

```
STORED
```

#### 2.3 데이터 조회 (get)

저장된 키(`hello`)를 호출하여 데이터가 올바르게 반환되는지 확인합니다.

- 입력

```
get hello
```

- 정상 응답

```
VALUE hello 0 5
arcus
END
```
