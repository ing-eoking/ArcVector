## 기본 통계 지표

### stats

통계 정보를 조회합니다.

```regex
stats [settings|items|slabs]\r\n
```

**매개변수(Parameters)**

- `settings`/`items`/`slabs` (선택)
  - 조회할 통계 정보 유형 (택 1)
  - 생략 시 일반 통계 정보 조회

**응답(Response)**

조회에 성공한 통계 정보는 `STAT` 블록으로 반환하며, 조회가 모두 완료되면 `END`를 반환합니다.

```regex
STAT <name> <value>\r\n
...
END\r\n
```

- `STAT ...`
  - 통계 항목명과 값을 출력
  - 조회된 통계 항목 개수만큼 이 블록이 반복해서 출력
- `END`
  - 데이터 반환의 종료를 의미

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |

## Prefix 통계 지표

### stats prefixes

모든 Prefix별 데이터 저장 통계 정보를 조회합니다.

```regex
stats prefixes\r\n
```

**응답(Response)**

통계 정보가 성공적으로 조회되면 각 Prefix의 데이터 저장 통계 정보를 `PREFIX` 블록으로 반환하며, 조회가 모두 완료되면 `END`를 반환합니다.

```regex
PREFIX <prefix> <statistics>\r\n
...
END\r\n
```

- `PREFIX ...`
  - Prefix 이름과 해당 Prefix의 통계 정보를 출력
  - 조회된 Prefix 개수만큼 이 블록이 반복해서 출력
- `END`
  - 데이터 반환의 종료를 의미

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |

### stats detail

모든 Prefix별 명령 수행 통계 정보를 조회하거나, 해당 통계 정보의 수집 여부를 설정합니다.

```regex
stats detail on|off|dump\r\n
```

**매개변수(Parameters)**

- `on`/`off`/`dump` (필수) : Prefix 연산 통계 처리 방식 (택 1)
  - `on` : 통계 정보 수집 여부 활성화
  - `off` : 통계 정보 수집 여부 비활성화
  - `dump` : 통계 정보 조회

**응답(Response)**

통계 정보 수집 여부가 성공적으로 변경되면 `OK`를 반환합니다.

```regex
OK\r\n
```

통계 정보가 성공적으로 조회되면 각 Prefix의 명령 수행 통계 정보를 `PREFIX` 블록으로 반환하며, 조회가 모두 완료되면 `END`를 반환합니다.

```regex
PREFIX <prefix> <statistics>\r\n
...
END\r\n
```

- `PREFIX ...`
  - Prefix 이름과 해당 Prefix의 통계 정보를 출력
  - 조회된 Prefix 개수만큼 이 블록이 반복해서 출력
- `END`
  - 데이터 반환의 종료를 의미

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |
