# 동적 설정 변경 명령

---

### config

특정 설정 값을 변경하거나 조회합니다.

```regex
config <name> [<value>]\r\n
```

**매개변수(Parameters)**

- `<name>` (필수) : 조회 또는 변경 대상 설정명
- `<value>` (선택) : 설정 값 (지정 시 변경, 생략 시 현재 값 조회)

> 지원 설정 목록

| 설정명 | 설명 | 허용 값 범위 |
| :--- | :--- | :--- |
| `verbosity` | 로그 출력 레벨 | `0 ~ 2` |
| `memlimit` | 데이터 저장용 최대 메모리 크기(MB) | 기존 값보다 큰 값 |
| `maxconns` | 허용 가능한 최대 동시 접속 수 | 기존 값보다 10% 이상 큰 값 |
| `max_list_size` | List 타입에서 허용되는 최대 요소 개수 | `10,000 ~ 1,000,000` |
| `max_set_size` | Set 타입에서 허용되는 최대 요소 개수 | `10,000 ~ 1,000,000` |
| `max_map_size` | Map 타입에서 허용되는 최대 요소 개수 | `10,000 ~ 1,000,000` |
| `max_btree_size` | B+Tree 타입에서 허용되는 최대 요소 개수 | `10,000 ~ 1,000,000` |
| `max_element_bytes` | 컬렉션 요소의 최대 크기(Byte) | `1 ~ 32,768` |
| `scrub_count` | [scrub](./03-데이터%20관리%20명령.md#scrub) 수행 시 제거 단위 | `16 ~ 320` |
| `max_stats_prefixes` | **prefix stats** 명령어 최대 조회 개수 | `0 ~ 100` |
| `zkfailstop` | ZooKeeper Session 기반 자동 Fail-stop 여부 <br> **(※ 클러스터 기능 사용 시 지원)** | `on` / `off` |
| `hbtimeout` | 하트비트 타임아웃 시간(ms) <br> **(※ 클러스터 기능 사용 시 지원)** | `50 ~ 10,000` |
| `hbfailstop` | 하트비트 기반 Fail-stop 기준 시간(ms) <br> **(※ 클러스터 기능 사용 시 지원)** | `3,000 ~ 300,000` |
| `auth` | 신규 연결 인증 요구 여부 <br> **(※ SASL 인증 보안 기능 사용 시 지원)** | `on` |

**응답(Response)**

설정 값이 **성공적으로 변경**되면 `END`를 반환합니다.

```regex
END\r\n
```

설정 값이 **성공적으로 조회**되면 설정명과 함께 현재 설정 값이 반환되며, 이후 `END`를 반환합니다.

```regex
<name> <value>\r\n
END\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |
| **`ERROR {reason}`** | 요청 처리 불가. `{reason}`에 구체적인 원인이 포함됨 |
