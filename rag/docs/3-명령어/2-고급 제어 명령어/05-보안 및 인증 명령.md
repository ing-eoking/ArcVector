# 보안 및 인증 명령

### sasl mech

서버에서 지원하는 SASL 인증 방식 목록을 조회합니다.

```regex
sasl mech\r\n
```

**응답(Response)**

지원하는 SASL 인증 방식 목록이 성공적으로 조회되면 `SASL_MECH`와 함께 인증 방식 목록이 반환됩니다. 인증 방식이 여러 개인 경우 공백(space)으로 구분됩니다.

```regex
SASL_MECH <mechanism> ...\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`NOT_SUPPORTED`** | SASL 인증 기능이 비활성화 상태 |
| **`AUTH_ERROR {reason}`** | 인증 방식 목록 조회 실패. `{reason}`에 구체적인 원인이 포함됨 |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |

### sasl auth

```regex
sasl auth [<mechanism>] <bytes>\r\n
<data>\r\n
```

**매개변수(Parameters)**

- `<mechanism>` (선택) : 사용할 SASL 인증 방식. 인증 과정을 시작할 때만 지정
- `<bytes>` (필수) : 인증 데이터의 실제 크기 (Byte)
- `<data>` (필수) : 인증 데이터 값

**응답(Response)**

인증이 성공적으로 완료되면 `SASL_OK`

인증 과정에서 추가 데이터 교환이 필요한 경우, `SASL_CONTINUE` 블록을 반환합니다.

```
SASL_CONTINUE <bytes>\r\n
<data>\r\n
```
