# 속성 제어 명령

### setattr

하나의 키를 지정하여 속성 정보를 변경합니다.

```regex
setattr <key> <attribute>=<value> [<attribute>=<value> ...]\r\n
```

**매개변수(Parameters)**

- [`<key>`](../../2-핵심%20개념/01-데이터%20모델.md#key) (필수)
- `<attribute>=<value>` (필수)
  - 변경할 속성과 해당 값의 쌍을 `속성=값` 형태로 지정
  - 공백(Space)을 구분자로 사용하여 여러 속성을 한 번에 변경 가능
  - 변경 가능한 속성 목록은 다음과 같음
    - [`expiretime`](../../2-핵심%20개념/01-데이터%20모델.md#attributes) : 모든 타입에서 변경 가능
    - [`maxcount`](../../2-핵심%20개념/02-컬렉션.md#maxcount), [`overflowaction`](../../2-핵심%20개념/02-컬렉션.md#overflowaction), [`readable`](../../2-핵심%20개념/02-컬렉션.md#readable) : 컬렉션 타입에서 변경 가능
    - [`maxbkeyrange`](../../2-핵심%20개념/02-컬렉션.md#maxbkeyrange) : B+Tree 타입에서 변경 가능

**응답(Response)**

속성 정보가 성공적으로 변경되면 `OK`를 반환합니다.

```regex
OK\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`NOT_FOUND`** | 대상 키가 존재하지 않아 변경 실패 |
| **`ATTR_ERROR not found`** | 존재하지 않거나 지원되지 않는 속성을 변경 |
| **`ATTR_ERROR bad value`** | 지정한 속성 값이 유효하지 않음 |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |

### getattr

하나의 키를 지정하여 속성 정보를 조회합니다.

```regex
getattr <key> [<attribute> ...]\r\n
```

**매개변수(Parameters)**

- [`<key>`](../../2-핵심%20개념/01-데이터%20모델.md#key) (필수)
- `<attribute> ...` (선택) : 공백(Space)을 구분자로 사용하여 나열한 속성 목록
  - 생략 시 조회 가능한 모든 속성 정보를 한 번에 반환
  - 속성 지정 시 해당 속성 정보만 조회 (조회 가능한 속성 목록은 아래 참조)
    - [`type`](../../2-핵심%20개념/01-데이터%20모델.md#attributes), [`flags`](../../2-핵심%20개념/01-데이터%20모델.md#attributes), [`expiretime`](../../2-핵심%20개념/01-데이터%20모델.md#attributes) : 모든 타입에서 지정 가능
    - [`count`](../../2-핵심%20개념/01-데이터%20모델.md#attributes)
    - [`maxcount`](../../2-핵심%20개념/02-컬렉션.md#maxcount), [`overflowaction`](../../2-핵심%20개념/02-컬렉션.md#overflowaction), [`readable`](../../2-핵심%20개념/02-컬렉션.md#readable) : 컬렉션 타입에서 지정 가능
    - [`minbkey`](../../2-핵심%20개념/01-데이터%20모델.md#attributes), [`maxbkey`](../../2-핵심%20개념/01-데이터%20모델.md#attributes), [`maxbkeyrange`](../../2-핵심%20개념/02-컬렉션.md#maxbkeyrange), [`trimmed`](../../2-핵심%20개념/01-데이터%20모델.md#attributes) : B+Tree 타입에서 지정 가능
    - [`trimmed`](../../2-핵심%20개념/01-데이터%20모델.md#attributes)

**응답(Response)**

조회된 속성 정보는 `ATTR` 블록으로 반환되며, 조회가 모두 완료되면 `END`를 반환합니다.

```regex
ATTR <attribute>=<value>\r\n
...
END\r\n
```

- `ATTR ...`
  - 조회한 속성과 값을 `속성=값` 형태로 출력
  - 조회한 속성 개수만큼 반복해서 출력
- `END`
  - 데이터 반환의 종료를 의미

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`NOT_FOUND`** | 대상 키가 존재하지 않아 조회 실패 |
| **`ATTR_ERROR not found`** | 존재하지 않는 속성을 조회 |
