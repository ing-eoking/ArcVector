# 클러스터 관리 명령

> [!TIP] 💡 도움말
>
> 클러스터 관리 명령은 클러스터 기능 사용 시 지원합니다.

## ZooKeeper 앙상블

### zkensemble set

서버에 설정된 ZooKeeper Ensemble 주소를 변경합니다.

```regex
zkensemble set <ensemble_list>\r\n
```

**매개변수(Parameters)**

- `<ensemble_list>` (필수) : 변경할 ZooKeeper Ensemble 주소

**응답(Response)**

ZooKeeper Ensemble 주소가 성공적으로 변경되면 `OK`를 반환합니다.

```regex
OK\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |
| **`ERROR {reason}`** | 요청 처리 불가. `{reason}`에 구체적인 원인이 포함됨 |

### zkensemble get

서버에 설정된 ZooKeeper Ensemble 주소를 조회합니다.

```regex
zkensemble get\r\n
```

**응답(Response)**

ZooKeeper Ensemble 주소가 성공적으로 조회되면 현재 설정 값이 반환됩니다.

```regex
<ensemble_list>\r\n
\n
\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |
| **`ERROR {reason}`** | 요청 처리 불가. `{reason}`에 구체적인 원인이 포함됨 |

### zkensemble rejoin

서버가 ZooKeeper Ensemble과의 연결을 끊고 대기 중인 상황에서 다시 ZooKeeper Ensemble에 연결합니다.

```regex
zkensemble rejoin\r\n
```

**응답(Response)**

ZooKeeper Ensemble에 성공적으로 연결되면 `Successfully rejoined`가 반환됩니다.

```regex
Successfully rejoined\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |
| **`ERROR {reason}`** | 요청 처리 불가. `{reason}`에 구체적인 원인이 포함됨 |
