# 데이터 관리 명령

## 데이터 일괄 제거(Flush)

### flush_all

모든 데이터를 일괄 제거합니다.

```regex
flush_all [<delay>] [noreply]\r\n
```

**매개변수(Parameters)**

- `<delay>` (선택) : 해당 시간(s) 후에 일괄 제거
- `noreply` (선택) : 설정 시 서버 응답을 생략

**응답(Response)**

성공적으로 제거되면 `OK`를 반환합니다.

```regex
OK\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |

### flush_prefix

특정 Prefix를 가진 데이터를 일괄 제거합니다.

```regex
flush_prefix <prefix> [<delay>] [noreply]\r\n
```

**매개변수(Parameters)**

- `<prefix>` (필수) : 일괄 제거할 Prefix
- `<delay>` (선택) : 해당 시간(s) 후에 일괄 제거
- `noreply` (선택) : 설정 시 서버 응답을 생략

**응답(Response)**

성공적으로 제거되면 `OK`를 반환합니다.

```regex
OK\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`NOT_FOUND`** | 대상 Prefix가 존재하지 않아 제거 실패 |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |

## 무효 데이터 정리

### scrub

> [!TIP] 💡 도움말
>
> scrub 명령은 [구동 옵션](../../4-운영%20및%20관리/0-서버%20환경%20설정/01-구동%20옵션.md)에서 확장 모듈 인자로 `ascii_scrub` 모듈이 지정되어야 사용할 수 있습니다.

서버에 남아 있는 불필요한 데이터를 정리합니다.
Scrub 작업은 백그라운드 쓰레드에서 수행되며, 실행 중에도 서버는 계속 요청을 처리할 수 있습니다.
정리 대상 데이터는 다음과 같습니다.

- **Expired/Flushed 데이터** : 만료되었거나 Flush 명령으로 삭제되었으나 서버에 아직 남아 있는 데이터
- **Stale 데이터** : 클러스터 환경에서 노드 추가/삭제로 인하여 더 이상 담당하지 않게 된 데이터

```regex
scrub [stale]\r\n
```

**매개변수(Parameters)**

- `stale` (선택)
  - Expired/Flushed 데이터와 Stale 데이터를 모두 제거
  - 생략 시 Expired/Flushed 데이터만 제거

**응답(Response)**

Scrub 작업이 성공적으로 시작되면 `OK`를 반환합니다.

```regex
OK\r\n
```

단, **예외 및 오류 응답 메시지**는 다음과 같습니다.

| 응답 메시지 | 설명 |
| :--- | :--- |
| **`BUSY`** | 현재 다른 Scrub 작업이 이미 수행 중 |
| **`CLIENT_ERROR {reason}`** | 사용자의 잘못된 요청. `{reason}`에 구체적인 원인이 포함됨 |
| **`SERVER_ERROR {reason}`** | 서버 내부 오류. `{reason}`에 구체적인 원인이 포함됨 |
