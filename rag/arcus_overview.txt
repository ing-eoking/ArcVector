# 제품 개요

## Arcus Memcached란?

**Arcus Memcached**는 대규모 고성능 서비스 환경에 최적화된 **분산 인메모리(In-Memory) 캐시 시스템**으로, 자주 조회되는 데이터를 느린 DB 대신 빠른 메모리에 임시 보관해 DB 병목을 방지하고 어플리케이션의 응답 속도를 안정적으로 향상시키는 **DB 캐시** 역할을 수행합니다.

오픈소스 [Memcached](https://memcached.org/) 아키텍처를 기반으로 설계되었으며, 이를 확장하여 B+Tree 등 다양한 컬렉션 자료구조를 지원함으로써 복잡한 비즈니스 로직을 효율적으로 처리합니다.

## 기존 Memcached 대비 주요 특징

Arcus Memcached는 기존 Memcached의 단순 구조와 운영상 한계를 극복하기 위해 다음과 같은 기술적 차별점을 갖추고 있습니다.

### 다양한 컬렉션 데이터 구조 지원

단순 Key-Value 저장을 넘어, 캐시 계층(Cache Layer)에서 복잡한 데이터 처리가 가능한 고성능 컬렉션 자료구조를 지원합니다.

- **지원 데이터 타입**
  - List, Set, Map, B+Tree 자료구조 제공
  - 단일 키(Key) 내에 다중 요소를 저장하고 개별 요소 단위의 삽입/제거/조회 제어가 가능

- **B+Tree 기반 데이터 최적화**
  - 데이터의 자동 정렬 및 특정 구간에 대한 범위 조회 기능을 지원
  - 순위 산정(Ranking), 시계열 데이터(Timeline) 등 정렬이 필요한 로직을 서버 측에서 직접 처리

- **서버 측 데이터 연산 기능**
  - 클라이언트가 전체 데이터를 가져오지 않고 서버에서 직접 삽입/제거/조회 수행
  - 네트워크 트래픽 최적화 및 애플리케이션 서버의 연산 부하 절감


### Prefix 기반의 논리적 데이터 관리

대규모 분산 환경의 데이터를 접두사(Prefix) 기반으로 구조화하여, 데이터 식별 및 관리 효율성을 제공합니다.

- **논리적 데이터 그룹화**
  - 업무 도메인(Business Domain)이나 데이터 성격에 따라 접두사(Prefix) 부여
  - 방대한 캐시 데이터를 용도별로 분류하여 관리 가시성 확보

- **Prefix 기반 데이터 일괄 제거**
  - 특정 Prefix를 가진 데이터 영역을 지정하여 해당 범위의 데이터를 일괄 제거하는 기능을 제공

- **데이터 그룹별 상세 분석**
  - Prefix별 아이템 수, 메모리 사용량, 연산 횟수 등 정밀 통계 제공
